# Инициализация PostgreSQL

Файл `sql/01_init_db.sql` создаёт структуру таблиц и заполняет их тестовыми данными для демонстрации алгоритма FEFO. При запуске через Docker Compose он автоматически выполняется в контейнере PostgreSQL после создания базы `fefo_optimization_db`.

Сценарий инициализации включает таблицы клиентов, продукции, партий, пользователей, заказов, строк заказов, резервов, производственных планов и строк планов. После вставки данных в конце сценария выполняется проверочный запрос с количеством записей в каждой таблице.

При необходимости повторно заполнить базу в Docker выполните из корня проекта:

```bash
docker compose down -v
docker compose up --build
```

Удаление тома необходимо, поскольку PostgreSQL запускает сценарии инициализации только при первом создании каталога данных.
