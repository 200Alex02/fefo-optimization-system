# FEFO‑План

Демонстрационный прототип корпоративной системы планирования производства молочной продукции по принципу **FEFO** (*First Expired, First Out*). Система показывает рабочий стол планировщика, позволяет задать параметры расчёта и сформировать проект производственного плана с тестовыми рекомендациями по использованию партий.

## Технологии

- **Frontend:** React и Vite;
- **Backend:** FastAPI;
- **Демонстрационные данные:** встроены в API;
- **Целевая БД:** PostgreSQL, схема находится в `database/sql/01_init_db.sql`;
- **Контейнеризация:** Docker Compose.

## Быстрый запуск для демонстрации

Требуется установленный Docker Desktop. В корневой папке проекта выполните:

```bash
docker compose up --build
```

После сборки откройте:

- интерфейс: [http://localhost:8080](http://localhost:8080);
- документацию API: [http://localhost:8000/docs](http://localhost:8000/docs).

Compose запускает три изолированных сервиса: React-интерфейс, FastAPI и PostgreSQL. При первом запуске PostgreSQL автоматически создаёт структуру таблиц и заполняет базу тестовыми данными из `database/sql/01_init_db.sql`.

На macOS можно запустить `./start-demo.sh`, на Windows — `start-demo.bat`.

## Локальная разработка без Docker

В проект добавлен автономный runtime Node.js в каталоге `.tools/node`. Он используется, если системный Node.js отсутствует или неисправен. Для macOS можно запустить обе части приложения одной командой:

```bash
./start-dev.sh
```

После запуска откройте [http://localhost:5173](http://localhost:5173). Остановка выполняется сочетанием `Ctrl+C`.

### Backend

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cd backend
uvicorn app.main:app --reload --port 8000
```

### Frontend

В отдельном терминале:

```bash
cd frontend
export PATH="$(pwd)/../.tools/node/bin:$PATH"
npm install
npm run dev
```

Vite откроет интерфейс по адресу [http://localhost:5173](http://localhost:5173). В development-режиме запросы `/api` автоматически перенаправляются на FastAPI по адресу `http://127.0.0.1:8000`.

## Демонстрационный сценарий

1. Откройте вкладку **«Обзор»** и проверьте показатели, заказы и сообщение о рисковых партиях.
2. Нажмите **«Создать план»**.
3. Укажите период, производственную линию и число заказов.
4. Нажмите **«Запустить расчёт FEFO»**.
5. Просмотрите рекомендации по партиям и нажмите **«Утвердить план»**.

## Ограничения текущей версии

Сейчас интерфейс использует демонстрационный репозиторий данных, а PostgreSQL уже включён в Docker-сборку и заполнен тестовыми сведениями. Слой доступа к данным выделен в отдельный модуль `backend/app/repository.py`; его методы будут заменены SQL-запросами при следующем этапе подключения API к базе. Схема PostgreSQL и аналитические запросы находятся в каталоге `database/`.
